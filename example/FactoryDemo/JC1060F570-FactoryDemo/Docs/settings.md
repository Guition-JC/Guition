# 设备设置与时间

[English](settings.en.md) | [文档索引](README.md)

从桌面打开 **设置**，可调整显示、声音、连接、时间和待机选项。页面中的持久化设置会在后续启动时恢复；如果某项操作失败，请根据页面提示检查对应硬件或网络状态。

## 常用设置

- **显示与声音**：调整背光亮度、音量和静音，以及频谱格线显示。
- **语言与连接**：切换中文或英文界面，开启或关闭蓝牙。
- **字体**：选择内置字体，或将 `.ttf` 文件放入 SD 卡根目录 `fonts/` 后在页面选择；字体加载失败时回退到内置字体。
- **天气**：选择状态栏显示的字段。天气服务商、城市和密钥通过联网后的天气网页配置，详见[网络连接与网页服务](network.md)。
- **自动待机**：选择关闭、30 秒、1 分钟、2 分钟或 5 分钟。待机内容可选择时钟、图片或视频，并可选择媒体及图片切换间隔。

## 时间与时区

设置页面可选择内部时钟或板载 RTC 作为时间源；RTC 不可用时页面会提示并保留内部时钟。在时钟应用中长按打开时钟设置，可调整时区并查看同步和 RTC 状态。

网络时间同步需要 Wi-Fi 或以太网已连接并可访问 SNTP 服务：

1. 确认设备已获得 IP 地址。
2. 在设置的时间区域点击“立即同步”。
3. 在时钟设置中查看同步状态；失败时检查网络、DNS 和 SNTP 服务是否可访问后重试。

当前构建的 SNTP 服务器为 `pool.ntp.org`，可通过 `sdkconfig` 查看；同步成功后程序会根据 RTC 状态协调 RTC 时间。设备断电后的走时能力取决于板载 RTC 及其供电条件。
