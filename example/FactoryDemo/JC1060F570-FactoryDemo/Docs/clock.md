# 时钟与自定义表盘

[English](clock.en.md) | [文档索引](README.md)

在桌面打开“时钟”。长按时钟页面可打开设置，选择钟表、数字翻页、数码管或图片数字样式，并调整时区。点击“完成”关闭设置；样式和时区会保存。

圆形钟表样式支持左右滑动切换表盘。可用内置表盘，也可从 SD 卡添加；格式和操作见下文。设备时间来源可在系统设置中配置。

## 圆形表盘

在圆形钟表页面左滑下一款、右滑上一款，顺序为：绘制 → 内置图片 → SD 扩展，首尾循环。
选择保存在 `clock_ui/face`，重开、重启及休眠继续使用；资源失效时显示绘制表盘。

## 新增 SD 样式

每款一个目录，仅扫描当前屏幕分辨率，按目录名排序：

```text
SD 卡根目录/
  clock/
    800x480/
      classic/
        placement.json
        dial.png
        hour.png
        minute.png
        second.png
        cap.png
    1024x600/
      classic/
        placement.json
        ...
```

可直接将仓库 `spiffs/800x480/clock/a01/` 或 `spiffs/1024x600/clock/a01/`
整目录复制到相应 SD 分辨率目录，并将 `a01` 改为自己的样式名。**复制后重新打开时钟**。
设备挂载路径为 `/sdcard/clock/<分辨率>/<样式>/`，SD 卡上无需创建 `sdcard` 目录。
放在 `/clock/` 根目录的旧式无 JSON 图片不参与新样式扫描。

表盘、时针、分针必需，秒针、中心盖可选；不需要的可选部件应从 JSON 中省略。
文件名由 JSON 指定，大小写须与实际文件一致；扩展名使用 `.png`、`.jpg`、`.jpeg`。
指针建议透明 PNG，所有指针原图朝向十二点。`preview.png` 不参与加载。

## 精简 JSON

800×480 示例（与内置资源一致）：

```json
{
  "screen": [800, 480],
  "dial_file": "dial.png",
  "dial_size": [440, 440],
  "dial_top_left": [180, 20],
  "screen_pivot": [400, 240],
  "hands": {
    "hour_hand_12": {"file": "hour.png", "size": [32, 165], "pivot": [16, 153]},
    "minute_hand_12": {"file": "minute.png", "size": [30, 207], "pivot": [15, 195]},
    "second_hand_12": {"file": "second.png", "size": [24, 263], "pivot": [12, 203]},
    "center_cap": {"file": "cap.png", "size": [38, 38], "pivot": [19, 19]}
  }
}
```

- 坐标、大小均为整数像素，原点在左上角。图片按原尺寸显示，不进行分辨率缩放。
- `screen_pivot` 是所有指针在屏幕上的公共转动中心；`pivot` 是各图片内部的轴心。
- 指针未旋转时的位置为 `screen_pivot - pivot`，无需重复保存 `draw_top_left_at_12`。
- 中心盖按自身 `pivot` 对齐公共轴心，绘制在指针之上，不旋转。
- JSON 大小必须与实际图片相同，图片各边不超过屏幕；表盘在屏幕内，公共轴心在表盘内，局部轴心在图片内。
- 删除 `decoded_*_bytes`、`source_vector`、`hand_zero_direction` 和各部件的重复左上角字段；这些额外字段会被忽略。
- 文件名只允许当前目录内的普通文件，不接受路径、`..`、隐藏文件或控制字符。
- JSON 最多 8 KiB；扫描最多 256 个目录项，总目录最多 64 款（含绘制与内置）。

内置表盘随当前板型分辨率的 `assets` 分区打包。修改内置文件后，需要重新编译并烧录资源分区。

## 资源不可用时

当前表盘及相邻表盘可能会被缓存。加载或解码失败的表盘会被跳过，重新进入时钟后才会重试；选中表盘不可用时回退到绘制表盘。已经解码的 SD 图片可能在拔卡后继续显示，但加载新图片需要 SD 卡。
