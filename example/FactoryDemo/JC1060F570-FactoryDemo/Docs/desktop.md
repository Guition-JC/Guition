# 桌面、显示与语言

[English](desktop.en.md) | [文档索引](README.md)

## 桌面操作

设备启动后显示触摸桌面。左右滑动切换桌面页面，点击图标打开应用，使用应用页面的返回或关闭控件返回桌面。顶部状态栏显示时间和连接状态等信息。全屏应用打开时会先显示名称和图标；图标不可用时显示备用标识，应用初始化完成后进入页面。

第一页提供触摸、设置、Wi-Fi、计算器、音乐、视频、串口、U 盘及 I2C 工具等入口，以太网或 GPIO 入口取决于构建配置。第二页提供时钟、AI 聊天、频谱、相册和工厂测试。具体可用功能受板型和配置影响。

## 开机视频与显示资源

启动时设备尝试播放内置视频，同时准备桌面；播放结束、不可用或超时后继续显示桌面。固件最多等待视频结束 8 秒。JC1060F570C 的资源来自 `spiffs/1024x600/`，其中 `video/` 为内置视频目录。修改内置图片或视频后重新编译并执行完整 `idf.py flash`，以更新 `assets` 分区。若屏幕显示异常，请检查板型配置、屏幕连接及资源分区是否完整烧录。

关于视频格式和 SD 卡播放，请参见[媒体播放](media.md)。

## 语言与字体

在“设置 → 语言”中选择中文或 English，设置会在下次启动时恢复。配网页面也可切换语言。中文显示需要可用的中文字体；没有可用字体时界面会提示仅支持 English。

设备通常使用独立 `fonts` 分区中的内置字体，覆盖常用中英文字符，但部分汉字可能缺失。需要更多字符时：

1. 将 `.ttf` 字体文件放在 SD 卡根目录的 `fonts/` 文件夹中并插入设备。
2. 打开“设置 → 字体”，选择该字体；也可以重新选择内置字体。
3. 如果字体加载失败，检查 SD 卡和文件，再重新选择；设备会回退到可用字体。

内置字体从 `fonts/embedded/` 打包。更换内置字体后重新编译并完整烧录，以更新独立字体分区。字体许可见工程中的 `fonts/LICENSE.txt`。
