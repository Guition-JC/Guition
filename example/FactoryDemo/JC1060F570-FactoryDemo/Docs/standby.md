# 自动待机与待机媒体

[English](standby.en.md) | [文档索引](README.md)

设备在桌面空闲一段时间后可以进入待机，显示时钟、轮播图片或静音视频。待机时间和内容均可在设备“设置”中配置；联网后也可通过设备网页设置待机内容。

## 设置自动待机

1. 在桌面打开“设置”，找到待机时间选项。
2. 选择关闭、30 秒、1 分钟、2 分钟或 5 分钟。默认值为 1 分钟，选择后会保存。
3. 返回桌面，等待所选的空闲时间。打开应用或弹窗时空闲计时会重新开始；选择“关闭”则不会因空闲自动待机。
4. 进入待机后触摸屏幕唤醒设备。

## 选择显示内容

在设置中选择待机模式并确认：

- **时钟**：显示时钟。
- **图片**：选择至少一张、最多 64 张图片，并设置 3、5、10 或 30 秒的轮播间隔。
- **视频**：选择一个视频；待机视频以静音方式播放。

选择的设置会保存。媒体列表包含可用的内置资源和 SD 卡文件；SD 卡图片放在根目录 `image/`，视频放在 `video/`。请在选择或播放 SD 卡素材时保持卡可读取。图片和视频的格式限制见[媒体与频谱](media.md)。

如果列表没有预期的文件，检查 SD 卡是否挂载、目录名称和文件格式；不符合解码尺寸或编码要求的文件可能无法显示或播放。
