# 媒体与频谱

[English](media.en.md) | [文档索引](README.md)

设备桌面提供音乐、视频、相册和频谱应用。音乐、视频和相册可以使用内置资源，也可以读取 SD 卡上的文件。使用 SD 卡时，将文件直接放入卡根目录下对应的目录：

```text
SD 卡根目录/
├── music/    音乐文件
├── video/    视频文件
└── image/    图片文件
```

设备内部将 SD 卡挂载在 `/sdcard`；无需在卡上创建 `sdcard` 目录。先插入可读取的 SD 卡，再打开对应应用。媒体列表为空时，检查卡是否挂载、目录和扩展名是否正确。文件扩展名符合要求不保证其内部编码或尺寸一定受支持。

## 音乐

打开桌面的“音乐”，使用播放/暂停、上一首、下一首和音量控件。音源按钮可在 SD 卡和经典蓝牙之间切换。本地播放会读取 `music/` 下的 MP3、WAV 和 AAC 文件，并包含内置示例曲目；文件是否可播放取决于实际编码。音量和静音偏好可保存并在启动后恢复。

要使用蓝牙音源，先在设备设置中启用蓝牙，在音乐页切换到经典蓝牙，然后从手机等设备连接并开始播放。若没有声音，检查当前音源、蓝牙连接、音量以及静音状态。

## 视频

打开“视频”后，可使用播放/暂停、上一段、下一段和音量控件。播放器扫描内置视频与 SD 卡 `video/` 中扩展名为 `.mp4` 的文件。

普通播放要求 MP4 内包含 MJPEG 视频和 AAC 或 MP3 音频，支持单声道或双声道音频。H.264 等视频编码不在此范围，仅将文件扩展名改为 `.mp4` 不会转换编码。分辨率和单帧大小还受设备解码缓冲区限制；无法播放时，请核对编码、图片尺寸以及文件是否完整。

## 相册

将 JPG、JPEG、PNG、SJPG 或 SPNG 图片放入 SD 卡 `image/`，然后打开“相册”浏览。应用也会读取内置图片。隐藏文件和不安全的文件名不会加入列表；图片尺寸和解码内存也会限制能否显示。若图片无法显示，可确认文件格式并缩小尺寸后重试。

## 麦克风频谱

打开“频谱”可查看板载麦克风采集声音的频谱。长按屏幕进入样式设置，选择常规柱状、点阵屏或格子显示；也可选择线性、视觉或对数频率分组，并设置格线。完成后设置会保存，下次打开继续使用。

频谱依赖音频输入设备。如果图形没有响应，请确认麦克风和音频设备正常，并在附近发出声音。退出应用后会释放采集资源。

照片和视频也可作为待机内容，配置方法见[自动待机与待机媒体](standby.md)。
