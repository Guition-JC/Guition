# 网络连接与网页服务

[English](network.en.md) | [文档索引](README.md)

设备支持 Wi-Fi 和以太网。连接并获得 IPv4 地址后，同一网络中的手机或电脑可访问设备的网页设置和天气配置。设备地址可在对应网络应用中查看。

## Wi-Fi 连接

在桌面打开 **Wi-Fi**，扫描附近网络，选择目标网络并输入密码连接。开放网络无需密码。连接后可在页面查看状态及 IP 地址，也可以断开连接或续订 DHCP 租约。若连接失败，请检查网络名称、密码和信号；页面的断开操作不会清除已保存的凭据。

### 手机二维码配网

1. 在 Wi-Fi 页面启动二维码配网。设备显示热点二维码、热点名称和密码，以及用于提交配置的一次性验证码。
2. 使用手机扫描二维码加入设备热点；无法自动加入时，可按屏幕信息手动连接。
3. 在手机浏览器打开任意网页进入配网门户，选择目标 Wi-Fi 并填写密码和验证码，然后提交。
4. 等待设备连接并获取 IP 地址。若连接失败，在设备上重新启动二维码配网，生成新的配网会话后重试。

配网二维码用于连接设备热点，验证码用于提交配置，两者用途不同。配网门户运行期间占用设备的 80 端口，普通网页设置会暂时停止，配网结束后恢复。

## 以太网

连接网线后在桌面打开 **以太网**，查看链路、IPv4 地址、子网掩码、网关及可用的收发统计。链路接通后仍需等待 DHCP 分配地址；页面也提供续订租约操作。若没有地址，请检查网线、交换机或路由器以及 DHCP 服务。

以太网页面还提供 TCP 和 UDP 吞吐测试：在设备已获得以太网 IPv4 地址后，填写对端 IPv4、端口、测试时长和报告间隔并启动；对端需要运行兼容的 iPerf 服务。页面显示运行状态、速率和传输量。

当前 `sdkconfig` 启用内部以太网控制器，使用 RMII 和 IP101 PHY，只支持一个以太网端口。可在 `idf.py menuconfig` 的 Ethernet Configuration 中检查设置。当前 RMII 输入时钟为 GPIO 13，TX_EN 为 12，TXD0/TXD1 为 8/9，CRS_DV 为 15，RXD0/RXD1 为 19/18，MDC/MDIO 为 53/10，PHY 复位为 17，PHY 地址为自动检测（-1）。更改板型或接线时，请对照硬件原理图检查这些值和引脚冲突；修改配置后需重新编译并烧录。

## 网页设置与天气

1. 使设备连接 Wi-Fi 或以太网并获得 IP 地址。
2. 在同一网络中的浏览器访问 `http://<设备IP>/` 打开网页设置；也可通过设备设置页面提供的入口或二维码访问。
3. 访问 `http://<设备IP>/weather` 配置天气，或者从网页设置进入天气页面。

天气页面支持 OpenWeather 和心知天气。选择服务商并输入对应 API Key，再选择按公网 IP 自动定位或手动输入城市，保存后可使用“立即更新”。OpenWeather 手动城市可使用 `Beijing,CN` 这样的城市和国家码；心知天气可使用城市名或拼音。已保存的密钥在页面留空时保持不变。设备设置中的天气选项控制状态栏显示的地名、天气、温度、湿度和风等字段。

天气更新需要互联网、有效的服务商密钥和城市配置。自动定位依赖公网 IP，位置可能不准确；可切换手动城市。无法访问网页时，先确认访问端与设备网络可互通，并确认设备没有处于配网门户模式。

网页设置和天气接口没有登录认证，API Key 存储在设备上。请在可信网络中使用，不要将服务暴露到公网。设备本地设置及时间同步见[设备设置与时间](settings.md)。
